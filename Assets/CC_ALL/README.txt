This code performs viewer centered stereoscopic rendering (interleaved, side-by-side and top-bottom) for display walls.

To get started, drag one of the scenes below from the CC_ALL asset folder into your Scene Hierarchy.

CC_LAVA_LED_WALL_SCENE is the scene with the screen set up for LAVA's LED Side by Side Stereo display Wall
CC_LAVA_LCD_WALL_SCENE is the scene for LAVA's Planar LCD Interleave Stereo display wall.
CC_Samsung_Acer27_SCENE is the scene for the Samsung or Acer 27" Autostereo display.

To adjust stereo rendering settings, go to the Project window, and in CC_ALL/CC select CC_SETTINGS. There you can set the stereo rendering mode as well as eye separation.

For more information on how to use this, go to:
https://github.com/doctorspiffy/CC_CANOE
